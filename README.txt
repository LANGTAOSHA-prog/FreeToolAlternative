ZenAlternatives 第二阶段静态多语言版

包含文件：
- index.html 主页面
- style.css 样式，支持浅色/深色模式
- app.js 多语言、搜索、分类、详情弹窗、收藏、排行、分享链接
- robots.txt 搜索引擎抓取规则
- sitemap.xml 站点地图

上线方法：把本文件夹内所有文件上传到 GitHub Pages / CloudBase / Netlify / Vercel 即可。

修改工具数据：打开 app.js，编辑 tools 数组即可。
修改网站域名：把 index.html、robots.txt、sitemap.xml 里的 https://www.zentools.xyz/alternatives/ 替换成你的真实网址。
